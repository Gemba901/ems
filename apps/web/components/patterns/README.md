# Shared patterns

Phase 2 compositions live here. See the [pattern APIs and examples](../../../../docs/frontend/phase-2-patterns.md) and [frontend conventions](../../../../docs/frontend/conventions.md).

Use direct imports such as `@/components/patterns/DataTable`. Patterns compose `ui/` primitives and tokens; module services, permissions and business rules stay with their callers. Interactive examples are in `/dev/ui`.
