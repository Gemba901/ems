# Implement the kaizen

After the HOD approves, the kaizen owner makes the change and records it.

## 1. Record what was done

Open the kaizen and complete the **Implementation** section:

- **Action taken:** What you changed. This is required before you can submit for verification.
- **After photos:** Up to five photos that show the change.
- **Result or saving (optional):** What improved, for example "Spill kit found in 10 seconds instead of 3 minutes".

Only the kaizen owner can edit this section.

## 2. Submit for verification

Select **Submit for Verification** when the change is done. The status becomes **Pending Verification**, and the reviewers are asked to confirm the result.

## 3. When the kaizen is returned for rework

If a reviewer returns the kaizen, it shows **Returned for Rework** with their remarks. Update the implementation and submit again. All verifications start again from the beginning.
