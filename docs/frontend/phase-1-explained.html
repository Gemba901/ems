A 30-minute walkthrough

These are the controls our modules can now share.

Phase 1 gives us a consistent set of buttons, inputs, selects, tabs, tables and dialogs. Today’s focus is how they look and when to use them.

ApprovedPending

Before

Each module built its own familiar controls. Colours, shapes and behaviour varied across the app.

What we now have

A shared kit with 16 new primitives, status colours and form helpers. Existing modules can adopt it in a later phase.

Presenter cue

Start with the repeated-control problem. Explain that the kit is built, while module migration is still ahead. Then move straight to the designs.

Status & next steps · 3 minutes
