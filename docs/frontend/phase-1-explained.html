Frontend consistency roadmap / Phase 01

One shared kit.
A consistent starting point.

We built the common controls that module developers can reuse: inputs, selections, overlays, navigation, tables and feedback, backed by shared colour tokens and accessible form helpers.

● In reviewImplemented on feat/frontend-kit-phase-1

The problem

Each module rebuilt familiar controls.

Buttons, inputs, tables and modals acquired different colours, spacing and behaviour. A small visual change could require edits across many module files.

What Phase 1 gives us

A shared place for common controls.

Developers can now import the same primitive, use its supported variants, and inherit shared styling and interaction behaviour. Module migration comes later.

The foundation

Where the work sits.

The roadmap has five layers. Phase 1 builds the primitive layer and brings forward the minimum status tokens it needs.

From input to feedback

A form is more than its fields.

The hand-written wrapper connects React Hook Form state to controls, labels, help text and validation feedback. The real showcase uses Zod v4 for its schema.

Composes with the child using Base UI useRender, preserving refs and handlers. Adds aria-invalid and description IDs.

Connect help text and errors to the control. Validation messages are announced as alerts.
